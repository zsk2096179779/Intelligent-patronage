## 1. 接口说明

### 1.1 通用规则

- **协议**: HTTPS
- **请求格式**: `application/json`
- **响应格式**: `application/json`
- **字符编码**: UTF-8
- **鉴权方式**: Bearer Token（部分接口需要）

### 1.2 请求头示例

```http
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## 3. 错误码定义

| 错误码 | 说明 | 处理建议 |
|--------|------|---------|
| **通用错误 (1xxx)** | | |
| 200 | 操作成功 | - |
| 1001 | 参数错误 | 检查请求参数 |
| 1002 | 未授权 | 需要登录 |
| 1003 | 无权限 | 当前角色无权限 |
| 1004 | 资源不存在 | 检查资源ID |
| **OTC相关 (2xxx)** | | |
| 2001 | OTC账户未开通 | 引导用户开通OTC |
| 2002 | OTC账户已开通 | 跳过开通步骤 |
| 2003 | OTC账户开通失败 | 提示用户联系客服 |
| **风险测评相关 (3xxx)** | | |
| 3001 | 风险测评未完成 | 引导用户完成测评 |
| 3002 | 风险测评已过期 | 引导用户重新测评 |
| 3003 | 风险等级不匹配 | 弹出警示弹窗 |
| 3004 | 风险不匹配未确认 | 需要用户确认后再提交 |
| **协议相关 (4xxx)** | | |
| 4001 | 协议未签署 | 提示缺少哪些协议 |
| 4002 | 协议签署失败 | 重试或联系客服 |
| **订单相关 (5xxx)** | | |
| 5001 | 订单不存在 | 检查订单号 |
| 5002 | 订单状态错误 | 不允许当前操作 |
| 5003 | 订单已提交 | 避免重复提交 |
| 5004 | 缺少签名 | 需要用户签名 |
| 5005 | 支付失败 | 检查支付信息 |
| **业务规则相关 (6xxx)** | | |
| 6001 | 金额低于最低限额 | 提示最低金额 |
| 6002 | 金额超过最高限额 | 提示最高金额 |
| 6003 | 产品未上架 | 产品暂不可购买 |

## 4.1 投资者画像模块

### 4.1.1 获取当前用户投资者画像

**接口**: `GET /api/investor/profile`  
**鉴权**: 需要  
**说明**: 获取当前登录用户的投资者画像信息

#### 请求示例

```http
GET /api/investor/profile
Authorization: Bearer {token}
```

#### 响应示例

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "userId": 1001,
        "otcStatus": 1,
        "otcAccountNo": "OTC20240101001",
        "riskLevel": "C3",
        "riskScore": 52,
        "riskAssessmentDate": "2024-01-15T10:30:00",
        "riskExpireDate": "2025-01-15T10:30:00",
        "isRiskExpired": false,
        "realName": "张三",
        "mobile": "138****1234",
        "bankName": "中国工商银行"
    }
}
```

#### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | Integer | 用户ID |
| otcStatus | Integer | OTC状态：0-未开通，1-已开通 |
| otcAccountNo | String | OTC账户号 |
| riskLevel | String | 风险等级：C1/C2/C3/C4/C5 |
| riskScore | Integer | 风险测评分数 |
| riskAssessmentDate | DateTime | 测评时间 |
| riskExpireDate | DateTime | 测评过期时间 |
| isRiskExpired | Boolean | 是否已过期 |
| realName | String | 真实姓名（脱敏） |
| mobile | String | 手机号（脱敏） |
| bankName | String | 开户银行 |

## 6. 附录

### 6.1 订单状态流转图

```
draft（草稿）
    ↓
pending（待审核） ← submit提交
    ↓
approved（审核通过）/rejected（审核拒绝）
    ↓
paid（已支付）
    ↓
completed（已完成）

任何状态 → cancelled（已取消）
```

### 6.2 风险等级映射表

| 用户风险等级 | 产品风险等级 | 数值 | 说明 |
|------------|------------|------|------|
| C1 | 低 | 1 | 保守型 |
| C2 | 中低 | 2 | 稳健型 |
| C3 | 中 | 3 | 平衡型 |
| C4 | 中高 | 4 | 积极型 |
| C5 | 高 | 5 | 激进型 |

**匹配规则**: 用户风险等级数值 >= 产品风险等级数值 → 匹配

### 6.3 签约流程完整步骤

```
1. 检查OTC状态
   ├─ 未开通 → 引导开通OTC
   └─ 已开通 → 下一步

2. 检查风险测评
   ├─ 未测评/已过期 → 引导完成测评
   └─ 已测评且有效 → 下一步

3. 阅读基础协议
   └─ 签署服务协议、风险揭示书等

4. 适当性匹配检查
   ├─ 不匹配 → 警示 → 用户确认 → 签署不匹配确认书
   └─ 匹配 → 下一步

5. 填写购买信息
   └─ 金额、分红方式、定投设置等

6. 阅读产品协议
   └─ 签署产品说明书、投顾协议等

7. 电子签名
   └─ 手写签名或验证码确认

8. 提交订单
   └─ 进入审核/支付流程
```
