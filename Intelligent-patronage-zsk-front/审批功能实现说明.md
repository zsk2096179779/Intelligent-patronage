## 二、后端需要实现

### 1. 审核通过接口

**接口地址：** `POST /api/strategy-combination/{id}/approve`

**请求参数：**
- 路径参数：`id` (Integer) - 组合ID（portfolioId）

**请求体：** 无（或可选的审核备注）

**响应格式：**
```json
{
  "code": 200,
  "message": "审核通过成功",
  "data": null
}
```

**业务逻辑：**
1. 根据 `portfolioId` 查询 `portfolios` 表
2. 检查组合是否存在
3. 检查当前状态是否为待审批（`listed = 0`）
4. 更新 `listed` 字段为 `1`（已上架/已审核）
5. 可选：记录审核时间、审核人等

**SQL示例：**
```sql
UPDATE portfolios 
SET listed = 1 
WHERE portfolio_id = #{portfolioId} AND listed = 0
```

### 2. 审核拒绝接口

**接口地址：** `POST /api/strategy-combination/{id}/reject`

**请求参数：**
- 路径参数：`id` (Integer) - 组合ID（portfolioId）

**请求体：**
```json
{
  "reason": "拒绝原因文本"
}
```

**响应格式：**
```json
{
  "code": 200,
  "message": "审核拒绝成功",
  "data": null
}
```

**业务逻辑：**
1. 根据 `portfolioId` 查询 `portfolios` 表
2. 检查组合是否存在
3. 检查当前状态是否为待审批（`listed = 0`）
4. 可选方案：
   - **方案A**：删除该组合记录
   - **方案B**：更新 `listed` 为 `-1`（表示已拒绝）
   - **方案C**：保留记录，添加拒绝原因字段
5. 可选：记录拒绝原因、拒绝时间、审核人等

**SQL示例（方案B）：**
```sql
UPDATE portfolios 
SET listed = -1 
WHERE portfolio_id = #{portfolioId} AND listed = 0
```

**如果数据库有拒绝原因字段：**
```sql
UPDATE portfolios 
SET listed = -1, reject_reason = #{reason}, reject_time = NOW()
WHERE portfolio_id = #{portfolioId} AND listed = 0
```

## 三、数据库字段说明

根据当前数据结构，`portfolios` 表应包含：
- `portfolio_id` (Integer) - 主键
- `listed` (Integer) - 上架状态
  - `0` = 未上架/待审批
  - `1` = 已上架/已审核通过
  - `-1` = 已拒绝（可选）

可选字段（用于记录审核信息）：
- `approve_time` (DateTime) - 审核通过时间
- `reject_reason` (String) - 拒绝原因
- `reject_time` (DateTime) - 拒绝时间
- `auditor` (String) - 审核人

## 四、接口实现建议

### Controller 层示例（Java Spring Boot）

```java
@RestController
@RequestMapping("/api/strategy-combination")
public class StrategyCombinationController {
    
    @Autowired
    private PortfolioService portfolioService;
    
    /**
     * 审核通过
     */
    @PostMapping("/{id}/approve")
    public Result approve(@PathVariable Integer id) {
        try {
            portfolioService.approve(id);
            return Result.success("审核通过成功");
        } catch (Exception e) {
            return Result.error("审核失败：" + e.getMessage());
        }
    }
    
    /**
     * 审核拒绝
     */
    @PostMapping("/{id}/reject")
    public Result reject(@PathVariable Integer id, @RequestBody RejectRequest request) {
        try {
            portfolioService.reject(id, request.getReason());
            return Result.success("审核拒绝成功");
        } catch (Exception e) {
            return Result.error("操作失败：" + e.getMessage());
        }
    }
}
```

### Service 层示例

```java
@Service
public class PortfolioService {
    
    @Autowired
    private PortfolioMapper portfolioMapper;
    
    public void approve(Integer portfolioId) {
        // 检查组合是否存在且为待审批状态
        Portfolio portfolio = portfolioMapper.selectById(portfolioId);
        if (portfolio == null) {
            throw new RuntimeException("组合不存在");
        }
        if (portfolio.getListed() != 0) {
            throw new RuntimeException("该组合已审核，无需重复操作");
        }
        
        // 更新状态为已上架
        portfolioMapper.updateListed(portfolioId, 1);
    }
    
    public void reject(Integer portfolioId, String reason) {
        // 检查组合是否存在且为待审批状态
        Portfolio portfolio = portfolioMapper.selectById(portfolioId);
        if (portfolio == null) {
            throw new RuntimeException("组合不存在");
        }
        if (portfolio.getListed() != 0) {
            throw new RuntimeException("该组合已审核，无需重复操作");
        }
        
        // 更新状态为已拒绝，并记录拒绝原因
        portfolioMapper.reject(portfolioId, reason);
    }
}
```

## 六、注意事项

1. **权限控制**：建议添加权限验证，只有审核人员才能执行审批操作
