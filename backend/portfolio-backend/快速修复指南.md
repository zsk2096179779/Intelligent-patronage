
# Spring Session 表创建 - 快速修复指南

## 问题说明

错误信息：`Table 'wealthadvisor.SPRING_SESSION' doesn't exist`

原因：数据库中缺少 Spring Session 所需的表。

## 解决方案

### 方案一：自动创建（已配置，推荐）

我已经将配置修改为 `spring.session.jdbc.initialize-schema=always`，应用启动时会自动创建表。

**操作步骤：**
1. 重启应用
2. 查看启动日志，确认表是否创建成功
3. 如果仍然报错，使用方案二手动创建

### 方案二：手动执行 SQL（如果自动创建失败）

如果自动创建不工作，请手动执行以下 SQL 脚本：

#### 步骤 1：连接到数据库

使用数据库工具连接到：
- 主机：`116.62.82.244`
- 端口：`3306`
- 数据库：`wealthadvisor`
- 用户名：`remote_admin`
- 密码：`123456`

#### 步骤 2：执行 SQL 脚本

**方式 A：使用数据库管理工具（推荐）**

1. 打开 Navicat、DBeaver、MySQL Workbench 等工具
2. 连接到数据库
3. 打开 `src/main/resources/sql/spring_session_schema.sql` 文件
4. 复制所有 SQL 语句并执行

**方式 B：使用命令行**

```bash
mysql -h 116.62.82.244 -P 3306 -u remote_admin -p wealthadvisor < src/main/resources/sql/spring_session_schema.sql
```

**方式 C：直接在数据库工具中执行以下 SQL**

```sql
-- 创建 SPRING_SESSION 表
CREATE TABLE IF NOT EXISTS SPRING_SESSION (
    PRIMARY_ID CHAR(36) NOT NULL,
    SESSION_ID CHAR(36) NOT NULL,
    CREATION_TIME BIGINT NOT NULL,
    LAST_ACCESS_TIME BIGINT NOT NULL,
    MAX_INACTIVE_INTERVAL INT NOT NULL,
    EXPIRY_TIME BIGINT NOT NULL,
    PRINCIPAL_NAME VARCHAR(100),
    CONSTRAINT SPRING_SESSION_PK PRIMARY KEY (PRIMARY_ID)
) ENGINE=InnoDB;

-- 创建索引
CREATE UNIQUE INDEX IF NOT EXISTS SPRING_SESSION_IX1 ON SPRING_SESSION (SESSION_ID);
CREATE INDEX IF NOT EXISTS SPRING_SESSION_IX2 ON SPRING_SESSION (EXPIRY_TIME);
CREATE INDEX IF NOT EXISTS SPRING_SESSION_IX3 ON SPRING_SESSION (PRINCIPAL_NAME);

-- 创建 SPRING_SESSION_ATTRIBUTES 表
CREATE TABLE IF NOT EXISTS SPRING_SESSION_ATTRIBUTES (
    SESSION_PRIMARY_ID CHAR(36) NOT NULL,
    ATTRIBUTE_NAME VARCHAR(200) NOT NULL,
    ATTRIBUTE_BYTES BLOB NOT NULL,
    CONSTRAINT SPRING_SESSION_ATTRIBUTES_PK PRIMARY KEY (SESSION_PRIMARY_ID, ATTRIBUTE_NAME),
    CONSTRAINT SPRING_SESSION_ATTRIBUTES_FK FOREIGN KEY (SESSION_PRIMARY_ID) REFERENCES SPRING_SESSION(PRIMARY_ID) ON DELETE CASCADE
) ENGINE=InnoDB;
```

#### 步骤 3：验证表是否创建成功

执行以下 SQL 查询，确认表已创建：

```sql
-- 查看表是否存在
SHOW TABLES LIKE 'SPRING_SESSION%';

-- 查看表结构
DESC SPRING_SESSION;
DESC SPRING_SESSION_ATTRIBUTES;
```

如果能看到两个表，说明创建成功。

#### 步骤 4：重启应用

表创建成功后，重启 Spring Boot 应用，错误应该消失。

## 验证配置

执行 SQL 后，可以通过以下方式验证：

1. **查看表结构：**
   ```sql
   SHOW CREATE TABLE SPRING_SESSION;
   SHOW CREATE TABLE SPRING_SESSION_ATTRIBUTES;
   ```

2. **查看表数据（如果有会话）：**
   ```sql
   SELECT * FROM SPRING_SESSION;
   SELECT * FROM SPRING_SESSION_ATTRIBUTES;
   ```

3. **检查应用日志：**
   - 启动后不应该再看到 `Table 'SPRING_SESSION' doesn't exist` 错误
   - 应该能看到 Spring Session 正常工作的日志

## 注意事项

1. **权限问题：** 确保数据库用户 `remote_admin` 有创建表的权限
2. **表已存在：** 如果表已存在，`CREATE TABLE IF NOT EXISTS` 不会报错，可以安全执行
3. **索引创建：** 如果 MySQL 版本不支持 `CREATE INDEX IF NOT EXISTS`，可以先删除索引再创建，或忽略索引创建错误（不影响功能）

## 如果仍然有问题

1. 检查数据库连接是否正常
2. 检查用户权限是否足够
3. 查看应用启动日志中的详细错误信息
4. 确认数据库版本是否支持相关 SQL 语法
