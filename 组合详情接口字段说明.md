# 组合详情接口字段说明

## 接口信息

**接口地址：** `GET /combos/{id}`

**接口描述：** 根据组合ID查询组合详情，包含基本信息、策略信息和收益指标

## 字段映射关系

### 图片中显示的字段 → 接口返回字段

| 图片显示 | 接口返回字段 | 数据类型 | 说明 | 数据来源 |
|---------|------------|---------|------|---------|
| **组合ID** | `portfolioId` | Integer | 组合的唯一标识 | `portfolios.id` |
| **组合名称** | `portfolioName` | String | 组合产品名称 | `portfolios.name` |
| **策略名称** | `strategyName` | String | 关联的策略名称 | `strategies.name` |
| **策略类型** | `strategyType` | String | 策略类型 | `strategies.strategy_type` |
| **组合类型** | `portfolioStrategyType` | String | 组合策略类型（如"成长"） | `portfolios.strategy_type` |
| **风险等级** | `riskLevel` | String | 风险等级（如"中高"） | `portfolios.risk_level` |
| **策略描述** | `description` | String | 策略描述信息 | `strategies.description` |
| **创建时间** | `createTime` | LocalDateTime | 组合创建时间 | `portfolios.created_at` |
| **资产规模** | `scale` | Double | 资产规模（亿元） | `strategies.scale` |
| **费率** | `feeRate` | Double | 费率（%） | `strategies.fee_rate` |
| **上架状态** | `listedText` | String | 上架状态文本："已上架"/"未上架"/"已拒绝" | 根据`listed`自动转换 |

### 额外字段（图片未显示，但接口也返回）

| 接口返回字段 | 数据类型 | 说明 | 数据来源 |
|------------|---------|------|---------|
| `listed` | Integer | 上架状态数字：0-未上架，1-已上架，-1-已拒绝 | `portfolios.listed` |
| `status` | String | 审核状态：draft/pending_review/approved/rejected | `portfolios.status` |
| `rejectReason` | String | 审核拒绝原因 | `portfolios.reject_reason` |
| `strategyId` | Integer | 策略ID | `strategies.strategyid` |
| `strategyRefId` | Integer | 策略引用ID | `strategies.strategy_ref_id` |
| `returnRate` | Double | 累计收益（%） | `portfolios.return_rate` 或 `strategies.return_rate` |
| `annualReturn` | Double | 年化收益（%） | `portfolios.annual_return` 或 `strategies.annual_return` |
| `maxDrawdown` | Double | 最大回撤（%） | `portfolios.max_drawdown` 或 `strategies.max_drawdown` |
| `sharpeRatio` | Double | 夏普比率 | `portfolios.sharpe_ratio` 或 `strategies.sharpe_ratio` |
| `volatility` | Double | 波动率（%） | `portfolios.volatility` 或 `strategies.volatility` |
| `winRate` | Double | 胜率（%） | `portfolios.win_rate` 或 `strategies.win_rate` |

## 前端使用示例

### JavaScript/Vue 示例

```javascript
// 调用接口获取组合详情
async function getPortfolioDetail(portfolioId) {
  try {
    const response = await fetch(`/combos/${portfolioId}`);
    const result = await response.json();
    
    if (result.code === 200) {
      const portfolio = result.data;
      
      // 直接使用返回的字段，无需转换
      return {
        id: portfolio.portfolioId,                    // 组合ID
        name: portfolio.portfolioName,                // 组合名称
        strategyName: portfolio.strategyName || '—',  // 策略名称（空则显示—）
        strategyType: portfolio.strategyType || '—',  // 策略类型（空则显示—）
        portfolioType: portfolio.portfolioStrategyType, // 组合类型
        riskLevel: portfolio.riskLevel,               // 风险等级
        description: portfolio.description || '—',    // 策略描述（空则显示—）
        createTime: formatDateTime(portfolio.createTime), // 创建时间（需要格式化）
        scale: portfolio.scale || 0,                  // 资产规模
        feeRate: portfolio.feeRate || 0,              // 费率
        listedText: portfolio.listedText              // 上架状态文本（已上架/未上架/已拒绝）
      };
    }
  } catch (error) {
    console.error('查询失败:', error);
    return null;
  }
}

// 格式化日期时间（前端处理）
function formatDateTime(dateTime) {
  if (!dateTime) return '—';
  const date = new Date(dateTime);
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const day = String(date.getDate()).padStart(2, '0');
  const hours = String(date.getHours()).padStart(2, '0');
  const minutes = String(date.getMinutes()).padStart(2, '0');
  return `${year}-${month}-${day} ${hours}:${minutes}`;
}

// 格式化资产规模（显示为亿元）
function formatScale(scale) {
  if (scale === null || scale === undefined) return '0.00 亿元';
  return `${scale.toFixed(2)} 亿元`;
}

// 格式化费率（显示为百分比）
function formatFeeRate(feeRate) {
  if (feeRate === null || feeRate === undefined) return '0.00%';
  return `${feeRate.toFixed(2)}%`;
}
```

## 数据来源表

### 主表：`portfolios` 表
- 组合基本信息
- 收益指标（优先使用）

### 关联表：`strategies` 表（LEFT JOIN）
- 策略信息
- 资产规模、费率
- 收益指标（作为默认值，当portfolios表没有数据时使用）

### 关联关系
```sql
LEFT JOIN strategies s ON p.strategy_id = s.strategy_ref_id
```

## 特殊说明

### 1. 上架状态文本
- `listedText` 字段自动根据 `listed` 值生成：
  - `listed = 1` → `listedText = "已上架"`
  - `listed = 0` → `listedText = "未上架"`
  - `listed = -1` → `listedText = "已拒绝"`

### 2. 空值处理
- 策略相关字段（`strategyName`, `strategyType`, `description`）可能为 `null`
- 前端应该使用 `|| '—'` 来显示占位符

### 3. 收益指标优先级
- 优先从 `portfolios` 表读取
- 如果为 `null`，则从关联的 `strategies` 表读取（兼容性设计）

### 4. 创建时间格式
- 后端返回 ISO 8601 格式：`"2025-11-13T18:19:05"`
- 前端需要格式化为显示格式：`"2025-11-13 18:19"`

### 5. 资产规模和费率
- `scale` 单位为"亿元"，前端需要添加单位显示
- `feeRate` 单位为百分比（%），前端需要添加%符号
